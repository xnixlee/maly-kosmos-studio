# Малый космос Studio

Open-source, local-first мастерская историй: свой мир и персонажи → сценарий по кадрам → голоса по ролям → текст, WAV и субтитры.

«Малый космос» — готовый пример. Можно создать другую вселенную с нуля: лор, законы, места, рассказчик, банк завязок, герои, их характеры, внешность, портреты и голоса полностью редактируются. Миры импортируются и экспортируются как JSON; созданные истории сохраняют снимок своего мира.

## Быстрый запуск

Нужен **Node.js 22+**. Python и веса моделей для OpenAI не нужны.

```sh
git clone https://github.com/xnixlee/maly-kosmos-studio.git
cd maly-kosmos-studio
npm ci
npm start
```

Открой **http://127.0.0.1:4321**. На macOS после установки зависимостей можно открывать `Запустить.command` двойным кликом. Студия работает, пока запущен сервер. Для остановки — Ctrl+C.

### OpenAI

1. В **Кабинете OpenAI** добавь имя и API-ключ. Можно хранить несколько ключей и переключаться между ними.
2. Нажми «Проверить доступ»: это запрос метаданных модели, без платной генерации.
3. В **Модели и голоса** выбери OpenAI / `gpt-5.6-luna`, глубину рассуждения и сохрани выбор.
4. Создай историю. Счётчик покажет потребление этой студии по каждому ключу в USD.

Используется Responses API, `store: false`, строгая JSON Schema, стандартный service tier. Запросы содержат выбранных героев, лор и завязку; они отправляются в OpenAI только при выборе облачного движка. Автоматического перехода из локального режима в облако нет. API-ключ можно также передать через `OPENAI_API_KEY`.

Текущий тариф Luna и дата проверки находятся в [`config/pricing.json`](config/pricing.json). Учитываются обычный ввод, чтение и запись кеша, весь output (включая reasoning), длинный контекст и фактически возвращённый service tier. Тариф фиксируется для каждой записи, чтобы обновление цен не меняло старые расчёты. Запросы без полученного usage помечаются как неизвестные, а не бесплатные. Расходы других приложений и баланс аккаунта доступны только в [кабинете OpenAI](https://platform.openai.com/usage). Подробности — [docs/billing.md](docs/billing.md).

### Локальные модели

| Движок           | Для чего                                        | Поддержка                                 |
| ---------------- | ----------------------------------------------- | ----------------------------------------- |
| MLX              | Генерация текста, стандартный комплект Qwen3 4B | Mac с Apple Silicon                       |
| Silero + Whisper | Русская речь и синхронизация слов               | Python 3.11–3.12, CPU; проверено на macOS |
| Silero → RVC MLX | Голоса персонажей                               | Mac с Apple Silicon                       |
| OpenAI           | Генерация текста без локальных весов            | Любая ОС с Node.js 22+ и доступом к API   |

В **Модели и голоса** сначала установи нужный движок, затем нажми «Скачать» у модели. Для установки Python по умолчанию используется `python3.11` (`python` на Windows); другой интерпретатор задаётся через `PYTHON_BIN`.

Можно подключить существующее окружение и веса: укажи Python для текста/озвучки, папку общих голосовых моделей и `rvc-mlx`. Так повторно используется уже установленный комплект без копирования и изменения внешних файлов.

Свою MLX-модель можно подключить по пути к папке или по Hugging Face repo + полному commit. RVC — по готовому `.npz` с соседним `.json` либо по закреплённому `.pth` на Hugging Face с последующей конвертацией. Отключение сохраняет файлы. Удаление доступно только для собственной загрузки студии, а не внешней подключённой модели.

Скачивание моделей и установка пакетов требуют интернета. После установки локальная генерация работает без него. Модельный формат/архитектура должны поддерживаться установленным движком; студия не обещает совместимость с любыми весами. Каталог — [`config/catalog.json`](config/catalog.json). Источники и общие зависимости закреплены по ревизиям, Silero проверяется по SHA-256. Условия использования моделей отдельны от лицензии кода — [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

## Рабочий процесс

- Выбери 1–6 героев, завязку, место, формат и длительность. Настрой абсурд, теплоту, тревогу, развязку и свободные требования.
- Создай 1, 3 или 5 вариантов. Готовые варианты сохраняются сразу, даже если остальная партия была прервана.
- Редактируй реплики, говорящего, действия в кадре, звуки и промпты изображений. Добавляй/удаляй сцены.
- Запроси новую версию по замечанию — исходная останется в библиотеке. Новая версия использует снимок канона исходной истории.
- Назначь голоса рассказчику и персонажам, настрой темп и высоту. Послушай реплику или озвучь всю историю.
- Экспортируй Markdown, JSON, чистый текст, WAV и SRT. Длительность в форме приблизительна; точная появляется после синтеза.

Кнопка «Сохранить» пишет сценарий на диск. Черновик правок сценария сохраняется в браузере. Лор сохраняется отдельной кнопкой: сохрани его перед переключением мира. Маленькие локальные модели могут ошибаться в языке и логике; результаты требуют авторского отбора. Схема проверяет структуру и говорящих, а не художественную правду. Изображения и видео не генерируются: студия подготавливает промпты и сценарный материал.

## Файлы и настройки

Копия `.env.example` в `.env` позволяет переопределить настройки. `.env` загружается при старте.

| Путь / переменная               | Назначение                                                 |
| ------------------------------- | ---------------------------------------------------------- |
| `data/` / `STUDIO_DATA_DIR`     | Личные миры, истории, подключения, голоса, журнал расходов |
| `models/` / `STUDIO_MODELS_DIR` | Скачанные веса                                             |
| `data/secrets/`                 | API-ключи; файлы с правами `0600`, каталог `0700` на POSIX |
| `.venv/`, `.venv-neural/`       | Необязательные Python-окружения                            |
| `vendor/`                       | Скачанный RVC-движок                                       |
| `FFMPEG_PATH`                   | Альтернативный FFmpeg вместо npm-пакета                    |
| `PORT`                          | Порт, по умолчанию 4321                                    |

В репозитории нет весов, ключей, пользовательских историй, локальных путей или виртуальных окружений. Не добавляй эти файлы с `git add -f`. Ключи локально хранятся в файлах, без шифрования диска приложением; не публикуются HTTP-сервером и не возвращаются клиенту. Защита ОС и доступ к самому компьютеру остаются важны. Для резервной копии пользовательского материала сохрани `data`, исключив `secrets`, если ключи не нужны в копии.

Сервер рассчитан на одного пользователя и слушает только loopback. Это не сервис с аккаунтами нескольких пользователей. Не выставляй его в интернет без отдельного слоя аутентификации и HTTPS. См. [SECURITY.md](SECURITY.md).

## Разработка

```sh
npm ci
npm run check
npm test
npm start
```

CI не скачивает модели и не требует ключей. Тесты включают расчёт стоимости, сохранение ключей и расходов, ошибочные ответы OpenAI, управление моделями, изоляцию миров, входные ограничения и сценарные структуры. OpenAI в тестах подменён тестовым транспортом; реальный API проверяется твоим ключом через интерфейс.

`node scripts/verify-api.mjs` дополнительно проверяет локальный API и настоящий синтез двух голосов на подготовленной машине. Не запускай его при активной пользовательской задаче. Архитектура — [docs/architecture.md](docs/architecture.md). В браузерах с WebMCP доступен инструмент чтения списка историй; работа без WebMCP полностью поддерживается.
